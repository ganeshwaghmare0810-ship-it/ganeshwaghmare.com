# Data Analyst Portfolio

A responsive beginner-friendly portfolio built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page content
- `style.css` — blue-and-white responsive design
- `script.js` — mobile menu, project filters, and current year
- `resume.pdf` — add your own resume PDF here (this file is not included)

## Run locally
1. Extract the ZIP.
2. Open the `data_analyst_portfolio` folder.
3. Double-click `index.html`, or open the folder in VS Code and use Live Server.

## Personalize before publishing
1. Check the name and headline in `index.html`.
2. Replace `your.email@example.com` with your real professional email.
3. Replace the GitHub and LinkedIn links with your own profile URLs.
4. Update project links to your actual repositories and add screenshots/results.
5. Add your resume PDF to this folder and name it exactly `resume.pdf`.
6. Adjust skill descriptions to match your real level. The dashboard graphic and figures in the hero are illustrative sample data, not actual achievements.
7. Save, refresh, and test all links on desktop and mobile.

## Publish for free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a repository, for example `my-portfolio`.
3. Upload `index.html`, `style.css`, `script.js`, and `resume.pdf` (if ready) to the repository root.
4. Open repository **Settings → Pages**.
5. Under build/deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
6. Wait for GitHub Pages to publish the website. Copy the published URL from the Pages section.

Tip: Never publish passwords, private customer data, or confidential datasets.
